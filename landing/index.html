MCP Server for AI Agents

Let your AI agent audit code using the Model Context Protocol. Start an audit, iterate through rules, report results — all programmatically.

# Available MCP Tools:
start_audit    - Begin a security audit session
get_rules      - Get batches of rules to check
report_results - Report pass/fail for each rule
get_report     - Get the final audit summary
search_rules   - Search for specific vulnerabilities
get_rule_detail - Get full details for a rule
